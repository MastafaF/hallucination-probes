# Hallucination probes

Runnable demonstrations of the LLM failure modes described in [*La paresse de penser*](https://mastafafoufa.com/en/#book) — small, honest experiments that show what large language models actually do, beyond the marketing.

> "LLM failures rarely look like errors. They look like fluent, confident, well-formed sentences — that happen to be wrong."

Each probe is self-contained: a short essay, an experiment, real model outputs, and a brief analysis. Read them to understand a pattern; run them to feel it.

## Why these exist

Most public material on LLM failure modes is either marketing ("our model is the most aligned!") or rage-bait ("LLMs are useless!"). Neither helps a working scientist think clearly about what models do and don't do.

These probes are the middle path: small, runnable experiments. The kind of thing I run before forming an opinion.
